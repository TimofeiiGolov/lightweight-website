# FPV ПОЛИГОН — браузерный симулятор FPV-дрона

Полноценный веб-симулятор учебно-боевого FPV-дрона с видом от первого лица.
Запускается прямо в браузере смартфона и десктопа, без установки.

**Стек (строго по ТЗ):** Three.js + TypeScript (strict) + Vite + Rapier3D (физика).
Без бэкенда, без внешних 3D-моделей и аудиофайлов — вся геометрия и звук процедурные.

---

## Быстрый старт

```bash
npm install
npm run dev        # http://localhost:5173
```

Продакшен-сборка:

```bash
npm run build      # dist/ готов к статичному хостингу (base './')
npm run preview    # локальный просмотр сборки
```

Папка `dist/` в архиве уже собрана — её можно сразу выложить на любой статичный
хостинг (GitHub Pages, Netlify, Vercel, обычный хостинг).

## Деплой на GitHub Pages (готовый workflow)

В репозитории есть `.github/workflows/deploy.yml`:

1. Залей проект в репозиторий GitHub (ветка `main`).
2. Settings → Pages → Source: **GitHub Actions**.
3. Каждый push автоматически собирает и публикует симулятор.

## Управление

### Мобильное (приоритет №1)
| Элемент | Действие |
|---|---|
| Левый стик | вверх/вниз — **газ** (не пружинит, как на аппаратуре), влево/вправо — **рыскание** |
| Правый стик | **тангаж** + **крен** (Mode 2) |
| ARM / DISARM | включение моторов (перед ARM газ должен быть на нуле) |
| DROP | сброс условного учебного груза |
| T+ / T− | наклон FPV-камеры |
| RST | ресет дрона на старт |
| II | пауза |

### Десктоп
- `W/S` — газ (виртуальный ползунок), `A/D` — рыскание, `стрелки` — тангаж/крен
- `ЛКМ` + движение мыши — тангаж/крен
- `Space` — ARM, `F` — сброс груза, `R` — ресет, `Q/E` — камера, `M` — ACRO/ANGLE, `P/Esc` — пауза

### Геймпад / аппаратура (USB HID)
Gamepad API, Mode 2: левый стик — газ/рыскание, правый — тангаж/крен.
`A` — ARM, `B` — сброс, `X` — ресет, `Y`/`LB` — камера, `Start` — пауза.

## Режимы

- **6 миссий**: Первый вылет, Лесной коридор (8 ворот), Точный сброс (3 зоны),
  Разведка огнём (движущиеся цели), Штурм бункера, Мастер полигона (комбо).
- **4 тренировки**: Точность (10 целей на время), Слалом, Висение (кольцо), Посадка.
- **Свободный полёт** — открытый полигон, мишени восстанавливаются из паузы.

Звёзды: 3★ — быстро / много времени в запасе, рекорды — в localStorage.

## Физика полёта

Собственная модель 6DOF на фиксированном шаге **120 Гц** (Rapier — столкновения):

- тяга вдоль оси корпуса: `thrust = TWR · m · g · (0.3·s + 0.7·s²)`, где `s` — обороты
  с учётом **spool-up** (моторы не мгновенные, ~0.18 с);
- линейное + квадратичное сопротивление: `a = -(c1 + c2·|v|)·v`;
- угловое управление PD-моментами: **Acro** (rate-контроль, кривая в стиле
  Betaflight Rates: RC Rate / Super Rate / Expo) и **ANGLE** (самовыравнивание);
- батарея 6S: просадка напряжения от газа и наработки, влияет на тягу;
- детекция крашей: резкое изменение скорости за шаг или переворот у земли
  → искры, дым, потеря управления, авто-ресет через 2.5 с;
- груз: баллистический снаряд (гравитация + сопротивление), проверка попадания
  по AABB зданий и земле, взрыв с радиусом поражения 6.5 м.

Все параметры — в `src/config.ts` (PHYS, CRASH, PAYLOAD, SIGNAL, SCORE),
настройки пилота — в меню «Настройки» (rates, TWR, масса, FOV, tilt, качество).

## FPV-картинка и OSD

- FOV 80–130° (по умолчанию 110), наклон камеры 0–45°, тряска от вибрации моторов и ударов;
- OSD в стиле Betaflight/DJI (canvas 2D): ARM/DISARM, режим, напряжение, RSSI,
  таймер, газ, скорость, высота, очки, цели, статус груза, прицел, маркеры попаданий;
- помехи сигнала: при удалении или потере прямой видимости — шум/статика,
  катящаяся полоса, при RSSI < 8 — «SIGNAL LOST» и дрожание управления;
- пост-обработка одним шейдером: виньетка, зерно, скан-линии, хроматическая
  аберрация (bloom — на desktop/высоком качестве);
- стили OSD: «аналог» (зелёный, скан-линии) / «цифровой» (cyan, чистый).

## Полигон

300×300 м: дорога с разметкой, 9 зданий (целые и разрушенные), бункер с входом,
линия окопов с бермами, мешки с песком, ~120 деревьев (instanced), проволочное
ограждение, техника (грузовики, танк), прожекторы (для сумерек), стартовый пад,
8 ворот слалома, 3 зоны сброса, 19 мишеней (щиты, манекены, бочки, машины и
пехота на маршрутах). Освещение: день / сумерки.

## Производительность

- фиксированный физический шаг 120 Гц, независимый от FPS;
- InstancedMesh для деревьев/мешков/столбов, переиспользуемые геометрии/материалы;
- без аллокаций в горячем цикле (переиспользуемые Vector3/Quaternion);
- адаптивное качество: авто / низкое / среднее / высокое (разрешение рендера,
  тени, пост-эффекты) + авто-понижение при просадке FPS;
- OSD перерисовывается на 30 Гц.

Целевое железо из ТЗ (Snapdragon 7 Gen 1 / A14) — стабильные 45–60 FPS на
среднем качестве.

## Что осознанно иначе, чем в ТЗ

- 3D-модели — процедурный low-poly вместо glTF из Blender: проект полностью
  самодостаточен, без внешних ассетов; при желании можно подменить меши в
  `world/Level.ts` и `drone/Drone.ts` на GLB.
- Звук — процедурный (Web Audio), без аудиофайлов: моторы синтезируются
  осцилляторами+шумом и следуют за газом.
- Мультиплеер не включён (как и указано в ТЗ).

## Дисклеймер

Условная игровая механика: «полезная нагрузка» — абстрактный учебный груз,
никаких реальных устройств, схем или инструкций. Симулятор полёта и меткости.
